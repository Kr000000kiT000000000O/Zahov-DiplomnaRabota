# Текст за предаване на Етап 1

**Тема:** Разработване на уеб приложение за магазин за велосипеди (BikeStore).

**Кратко описание:** BikeStore е уеб приложение за магазин за велосипеди с каталог, онлайн покупки и резервиране на велосипеди под наем. Предвидени са три потребителски роли – клиент, служител и администратор. За Етап 1 са подготвени концепция, проучване на три сходни приложения, архитектура, начална структура на ASP.NET Core MVC, модел на SQL Server база данни и GitHub документация.

**Забележка:** Пълната реализация на покупки, наеми, административен CRUD и публичното публикуване са задачи за следващите етапи.
