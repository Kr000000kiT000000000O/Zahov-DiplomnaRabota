# План за разработване, рискове и приемане

## Етап 1 – Концепция и проучване (текущ)

- Анализ на Bike Center, Decathlon и BikesBooking.
- Идентифицирани бизнес процеси, целеви роли, критерии за приемане.
- Избрана технология и слоеста архитектура; план за Strategy pattern.
- Начална структура с 5 контролера, 6 домейн изгледа, 5 business entities + Identity.
- ER диаграма, Code First модел, SQL скрипт, инструкции за миграция.
- README, GitHub Actions CI, начални тестове.

## Етап 2 – Основни процеси

- Реален CRUD за велосипеди и категории; изрично управление на роли.
- Количка, checkout и запис на Orders/OrderItems.
- Поток за наем с дати, проверка на наличност и транзакция.
- Промяна на статуси на покупки/наеми от служител.
- Серверна и клиентска валидация, съобщения на български.

## Етап 3 – Качество, разгръщане и защита

- Strategy за стандартна/промоционална или дългосрочна тарифа.
- Unit + integration тестове, отчет за >=65% покритие на изпълнимите редове от бизнес логиката.
- Проверки за SQL Injection, XSS, CSRF и контрол на достъпа.
- 403 и 404 персонализирани страници, responsive проверки.
- Deployment на публичен URL, демонстрационни акаунти за Client/Employee/Admin със сигурна отделна конфигурация.
- CI/CD build, test и deployment след успешно преминаване на тестовете.
- Демонстрация на цялостния процес и окончателна документация.

## Рискове и мерки

| Риск | Влияние | Мярка |
|---|---|---|
| Двойно резервиране | Високо | Транзакционна проверка, интеграционни тестове |
| Поръчка при нулева наличност | Високо | Наличност + атомарно намаляване на склад |
| Неправомерен достъп | Високо | Identity, Authorize, проверки за собственост |
| Неподдържана .NET 8 след 10.11.2026 | Високо при публичен deployment | .NET 10 + VS 2026 преди production |
| Сложна настройка на SQL Server | Средно | LocalDB default, ясни миграционни инструкции |
| Публикувани тайни в GitHub | Високо | User Secrets, `.gitignore`, secret scanning |
| Прекалено голям обхват | Средно | MVP приоритети и ясно отлагане на допълнения |
